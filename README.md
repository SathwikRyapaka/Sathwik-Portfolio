## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SathwikRyapaka/Sathwik-Portfolio.git

# Navigate into project directory
cd "Sathwik Portfolio"

# Install dependencies
npm install

# Run development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
